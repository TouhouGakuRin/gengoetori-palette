## 幻歌鸟调色盘 v1.1.4

### 修复：桌面版打不开

上一版把用户数据放在 `%LOCALAPPDATA%` 下，在某些机器上这个目录被组策略或安全软件锁死，程序一启动就报「数据目录建不起来」然后退出。

现在改成**优先用程序旁边的 `userdata\`**：解压到哪儿，数据和设置就跟着哪儿走，拷到 U 盘也能带走。实在写不进去时才退回系统目录，最后才用本次启动的临时目录，并且会明确告诉你当前用的是哪个。

### 新增

- **数据与备份面板**（设置 → 数据与备份）：显示数据实际存在哪里、占用多少、可导出成 JSON、可导入恢复、可恢复出厂（只清本程序的数据）。
- **模块导航**：音阶 / 对比 / 地图 / 变形 / 进行台 / 测验 / MIDI 七个工作区，顶栏切换，`Alt+1…7` 直达；切回来时停在原处。
- 版本号写进页脚和设置面板，出问题时一眼能报出是哪个版本。

### 改进

- 窄窗口下音阶库变成抽屉，不再把详情挤到屏幕外。
- 主音条常驻，滚到地图或进行台也不会丢掉当前调性。
- 谱面不再被 `max-width` 压小，长谱横向滚动而不是缩成小字。
- 键盘焦点可见，`Tab` 能看到自己在哪。

### 下载哪个

| 文件 | 适合 | 说明 |
|---|---|---|
| `幻歌鸟调色盘-1.1.4-win-x64.zip` | 日常桌面使用 | 解压即用，不写注册表；需要系统有 WebView2 运行时（Win10 1903+ 与 Win11 自带） |
| `幻歌鸟调色盘-1.1.4-web.zip` | 任何浏览器 / 分享 | 解压后双击 `index.html` 即可，不需要安装任何东西 |

两个包都不需要管理员权限。桌面版首次启动会在 exe 旁边建 `userdata\` 存设置和进行台。

### 已知限制

- 仅 64 位 Windows。
- 打印功能尚未接上（宿主还没接到 `ShowPrintUI`），请用导出 PNG 代替。
- 分享链接携带的是音乐内容（音阶、主音、和弦、进行台），外观与输出设备设置留在本机。
